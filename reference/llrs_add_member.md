# Add a contributor to the registry

Add a contributor to the registry

## Usage

``` r
llrs_add_member(name = NULL, role = "Collaborator", path = ".")
```

## Arguments

- name:

  Character name of the contributor.

- role:

  Either Collaborator or Publisher.

- path:

  Path to the project.

## Value

`NULL`

## Examples

``` r
if (FALSE) { # \dontrun{
llrs_use_governance()
llrs_add_member(NULL)
} # }
```
