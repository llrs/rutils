# Check package version

Check package version

## Usage

``` r
llrs_check_pkg_version(repo, path = ".")
```

## Arguments

- repo:

  Github repository.

- path:

  Local path to the repository.

## Value

TRUE if successfull

## Examples

``` r
if (FALSE) { # \dontrun{
llrs_check_pkg_version("llrs/rutils")
} # }
```
