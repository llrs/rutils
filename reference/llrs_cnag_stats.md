# Read the CNAG stats

Read the stats of the samples processed by CNAG.

## Usage

``` r
llrs_cnag_stats(path)
```

## Arguments

- path:

  Path to excel file.

## Value

A data.frame with the data and the name of the project from the file
name.

## References

[CNAG](https://www.cnag.eu/)
