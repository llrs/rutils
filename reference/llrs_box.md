# Create positions of a box

Create a data.frame with the positions of the sample in a square box

## Usage

``` r
llrs_box(size)
```

## Arguments

- size:

  A numeric value with the number of rows or columns.

## Value

A data.frame with the rows and columns.

## Examples

``` r
box10 <- llrs_box(10)
box9 <- llrs_box(9)
```
