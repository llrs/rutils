# Add the governance

To make clear expectations and how people can join projects state how
their contributors can lead to higher rights (and responsibilities).

## Usage

``` r
llrs_governance(path = ".")
```

## Arguments

- path:

  Path to the directory where the file will be added.

## Value

A logical value if the file has been added.
