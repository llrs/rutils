# Changelog

## rutils (development version)

- Add functions to manage CNAG projects for `cellranger multi`.
- Make
  [`llrs_cellranger_clean()`](https://llrs.github.io/rutils/reference/llrs_cellranger_clean.md)
  more useful (keeping metrics).
- Create folders just once in
  [`llrs_cnag_symlinks()`](https://llrs.github.io/rutils/reference/llrs_cnag_symlinks.md)
- Set up environment variables in
  [`llrs_profile()`](https://llrs.github.io/rutils/reference/llrs_profile.md).
- New function
  [`llrs_check_pkg_version()`](https://llrs.github.io/rutils/reference/llrs_check_pkg_version.md)
  to compare github version with local version.

## rutils 0.0.1

- Add targets functions.
- Add functions to help with [CNAG](https://www.cnag.eu/) projects.
- Add new function for transcriptomics.
- Add new function for file names.
